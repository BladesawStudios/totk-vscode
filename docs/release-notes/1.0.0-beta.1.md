# Features
- Python is gone. Everything now runs in a built-in C# host, so there is nothing to install or set up
- Much faster startup and indexing. The RomFS and canonical path indexes take about 10 seconds instead of a minute
- Array textures: pick a layer in the texture viewer, and replace a single layer from a DDS. A DDS with the wrong size, format or mip count is converted to fit
- Opus-coded BWAV (the cutscene and voice streams) can now be played and replaced
- Textures can be exported as JPEG

# Tweaks
- BYML files with hash maps (`!h32` / `!h64`, such as the voice tables) are shown as YAML and save back unchanged
- Archives written back unchanged are byte for byte identical
- BWAV preview plays a looping sound once instead of repeating it with a fade
- Fonts replaced with a `.bfotf` use the same key as the game's own fonts
- Failures now say what was wrong with the file instead of silently trying something else
- Add-ons: `getPython()` now returns the path of the TKVSC host, and `bridgePath` is unused

# Fixes
- Multi-line strings in BYML gained an extra newline each time they were saved
- BYML hash maps showed up as `<oead.byml.Hash32 object>`
- Stereo prefetch BWAVs played their second channel from the wrong place
- BC1 textures were always shown opaque
- Array textures only ever showed their first layer

# Removed
- AINB, ASB, BAEV and RSTB support
- The Python setup, Select Python and Browse for python.exe commands, and the Python Path and Use Native Host settings
- Python handlers for add-ons (`registerBridgeHandler` and `bridgeHandlers`). Add-ons with their own file types should read and write them from a custom editor with `readRawBytes` / `writeRawBytes`
