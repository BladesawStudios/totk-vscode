# Upgrading from a beta
- TKVSC moved to a new publisher, so VS Code installs 1.0.0 as a separate extension and the old one stays installed. TKVSC offers to uninstall the old one on startup, or you can uninstall `TKVSC-Team.totk-vscode` yourself
- Add-ons made for the old publisher have to be replaced too. Uninstall them before the old TKVSC, then install the versions from Addon Release 5
- Your settings carry over, but the Your Projects list does not. Add your projects again with Add Projects via File Explorer or Import TKMM Projects. The setup prompts may also appear again, and the indexes are rebuilt on first launch
- There is now one VSIX per platform. Download the one for your system: `win32-x64`, `linux-x64`, `darwin-x64` or `darwin-arm64`

# Features
- Python is gone. Everything now runs in a built-in C# host, so there is nothing to install or set up
- Much faster startup and indexing. The RomFS and canonical path indexes take about 10 seconds instead of a minute
- Array textures: pick a layer in the texture viewer, and replace a single layer from a DDS. A DDS with the wrong size, format or mip count is converted to fit
- Opus-coded BWAV (the cutscene and voice streams) can now be played and replaced
- Textures can be exported as JPEG
- Flag names in `GameDataList`: each `Hash` shows its name as a comment, from the community's cracked hash list (about 30,000 names)
- Particle colours in Vfx3 data (the `PtclBin` in `.vsetb.byml` files) can be read and edited as text
- Switch 2 textures can be viewed and edited, so Switch 2 games can be supported through add-ons. See the new Ocarina of Time add-on in Addon Release 5
- Open any file in the hex editor from the right-click menus and the editor title bar
- Add-ons can add a whole game: new profile fields cover names, dictionaries and XLink versions, and a game's add-on can ship a .NET plugin that adds formats, compression and commands to the host

# Tweaks
- BYML files with hash maps (`!h32` / `!h64`, such as the voice tables) are shown as YAML and save back unchanged
- Archives written back unchanged are byte for byte identical
- `Tag.Product` rebuilds its `RankTable` the way the game does, so an unchanged table saves byte for byte identical
- BWAV preview plays a looping sound once instead of repeating it with a fade
- Fonts replaced with a `.bfotf` use the same key as the game's own fonts
- XLink files from newer XLink versions open
- The texture viewer names more texture formats
- Failures now say what was wrong with the file instead of silently trying something else
- Add-ons: `getBridge()` has a new `getHost()` (the path of the TKVSC host). `getPython()` still works as an alias, and `bridgePath` is unused. See the [API changelog](../api/CHANGELOG.md) for profile changes

# Fixes
- Search within archives
- File operations occasionally didn't work
- Saving from the hex editor into an archive wrote BYML and other text formats wrongly
- BYML strings starting with a YAML indicator such as `%` were not quoted
- Multi-line strings in BYML gained an extra newline each time they were saved
- BYML hash maps showed up as `<oead.byml.Hash32 object>`
- Stereo prefetch BWAVs played their second channel from the wrong place
- BC1 textures were always shown opaque
- Array textures only ever showed their first layer

# Removed
- AINB, ASB, BAEV and RSTB support
- The Python setup, Select Python and Browse for python.exe commands, and the Python Path and Use Native Host settings
- Python handlers for add-ons (`registerBridgeHandler` and `bridgeHandlers`). Add-ons with their own file types should read and write them from a custom editor with `readRawBytes` / `writeRawBytes`
