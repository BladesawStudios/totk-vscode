# Features
- In depth loop-point editor
- Group audio editor
- Replace multiple audio tracks with the same track
- Open `BFRES` files like an archive: material animations and each model's materials can be edited as YAML, and parameter names are read from the game's `ExternalBinaryString.bfres`
- Particle files (`.vsetb.byml`) open like an archive, with a file per emitter, so a big file like `static` no longer has to be edited as one document
- Export files as their decompressed data (`zstd`)
- Recipes system! a `.recipe.yaml` makes a whole mod from a few variables (like `color`) and the game files to change, so it can be remade in another colour by changing one line. Run it from the right-click menu or **TKVSC: Run Recipe**, or check it first with **TKVSC: Preview Recipe Changes**
- Recipe steps: `tint` (recolours particles, materials, material animations and textures, with `x 4` for brighter), `replace`, `copy` and `delete`. `include:` pulls in other recipes
- Particle emitters list the textures they use, so a recipe can point one actor's effects at its own recoloured copy of a texture instead of changing everything that shares it

# Tweaks
- Replacing a track in a BARS will automatically pull in the BWAV
